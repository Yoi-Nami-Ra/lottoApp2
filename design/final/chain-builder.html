Chain builder outline — final (LTA-21)

One chain, opened from the chain list (LTA-32), as an indented outline under the source it runs against. "+" adds a block beneath a row through the add-block sheet (LTA-22). Run lives in the bottom action bar. Any block's output can be saved and is listed under the outline. Rev. 2 follows spec 003 and the build in LTA-23; NEW marks frames added since rev. 1. Approved 2026-09-30; LTA-33 closes where the build still differs.

Notes for the implementer

  • Title area. The chain's name is the navigation title; "Source" and the source's name sit under it. The back button reads "Chains" and belongs to the screen, not the system, so it can ask before leaving (FR-032); swipe-back is off.
  • Structure. A native List, one row per node, indented 22 pt per depth with a guide line to the parent. The source row is always first, can't be removed and has no fold chevron.
  • Adding. "+" on a row opens the add-block sheet (LTA-22) with that row as parent. It shows on the source and every block except Count All Elements, whose single number ends a branch. Adding under a node that already has a child creates a branch.
  • Tapping a row. A block that has a value opens its output (the result page); a block without one (not run, running or failed) opens the edit sheet. Edit is always in the long-press menu, so a block with a result can still be changed.
  • Removing. Trailing swipe or long press. A block with children asks first, naming how many go ("Remove 3 Blocks"); a childless block goes without an alert.
  • Saving. A leading swipe or long press offers "Save Result" on a block with a value that isn't saved yet. Saved blocks show a bookmark. Saved results are listed under the outline, newest first, as the block path ("Suffix → Count Unique Elements"), the source and when. Badges: "Out of date" (the source's data changed), "Source unavailable", "Chain changed since" (the chain was edited after saving). Tap opens the saved output; swipe deletes it.
  • Run. A single "Run" button in the bottom bar: disabled with no blocks and while running (label "Running…" with a spinner).
  • Out of date. After any edit following a run, or when the source's data has changed: a banner above the outline, old summaries struck through with an "Out of date" badge, new blocks "Not run".
  • Failed. A failed block shows its reason in red instead of a summary ("Too large — over 5,000,000 sub-combinations", "z must be below this source's draw size"); blocks under it read "Not run — an earlier block failed". Siblings are unaffected.
  • Draft. Unsaved results survive the app going to the background as a draft; reopening the chain asks "Restore unsaved results?" (Restore / Discard).
  • Accessibility. Each row reads as "<block>, <parameter>, level <n>, <summary or state>". "+" is labelled "Add block under <block>". At accessibility text sizes the summary wraps under the title instead of sitting to its right, and the indent per level shrinks to 12 pt.
  • Tokens. Guide line borderPrimary; stale badge and banner warningYellow at 25 %; failure text errorRed; bookmark and swipe-to-save primaryBlue.
