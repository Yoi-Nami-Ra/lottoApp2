LTA-28 · Compact and wide source cards

LTA-5: the start page picks the card by horizontal size class. Compact width (iPhone, narrow iPad split view) gets a one-row card — severity dot, name, refresh icon — that expands inline to show the details. Regular width (iPad, Mac) keeps today's full card, laid out in an adaptive grid. Only MBNet exists today; the other sources are illustrative. Selection, the Next bar and the sync behaviour are unchanged.

Notes for the implementer

  • Switch. horizontalSizeClass == .compact → compact card in a single column; .regular → full card in a LazyVGrid with .adaptive(minimum: ~320). No platform checks, so iPad split view and Mac window resizing follow automatically.
  • Compact row. Severity dot · name (checkmark when selected; "Not synced" inline when never synced) · refresh icon button · disclosure chevron. Minimum height 52 pt; the whole row except the two buttons selects the source, as today.
  • Expand. The chevron toggles an inline details block: record count, last-sync badge (severity-coloured, as on the full card), first and latest record. Expanded state lives in SourceEntry.State (an isExpanded flag toggled by an action), per TCA; several cards can be expanded at once; collapsed by default and not persisted.
  • Refresh. Icon-only on compact, labelled "Refresh" / "Refreshing" for VoiceOver; same spin and dimmed styling as the full card's button.
  • Full card. Unchanged from today, including its accessibility-size reflow. Cards in one grid row share the row's height.
  • Accessibility. The dot is decorative; severity is read from the badge text (compact: announced with the name, e.g. "MBNet Server, Last synced: 30 Sep 2026 at 09:12", or "Not synced"). The chevron is labelled "Show details" / "Hide details". At accessibility text sizes the compact row lets the name wrap onto two lines before the buttons shrink, and the details grid becomes one column.
  • Skipped note. Spec 005's note sits in the compact details as a full-width row between the Records / Last sync row and the First / Latest record row. LTA-4's "~N missing" line, once built, goes in the same details block.
  • Expand animation. The chevron animates the change (snappy), and no animation is used when Reduce Motion is on.
  • Wide Next bar. At regular width the Next button is 320 pt wide (one grid column) at the trailing edge.
  • Tokens. New tokens for the dot size, compact row height and padding, and the grid's minimum column width; colours reuse the existing severity and refresh tokens.
