Chain list — final (LTA-32)

The Blocks page as the list of saved chains (spec 003 FR-017), reached with Next on the start page. Chains aren't tied to a source: the list is the same for every source, and the header names the source a chain will run against when opened (LTA-21). Built from the current BlocksPageView; NEW marks what the build in LTA-23 doesn't have yet (LTA-33). Approved 2026-09-30.

Notes for the implementer

  • Header. Unchanged: "Source" and the source's name only, shrinking rather than truncating for long names (down to 60 %, up to three lines). Record counts and sync state stay on the start page, so nothing here refreshes while the page is open (FR-024).
  • Rows. Chain name and "N blocks" ("1 block"). No last-run, saved-result or out-of-date details: those live in the editor (LTA-21). Chains are sorted by name, case-insensitive.
  • New chain. Always the last row. It creates a chain named "New chain" and opens it in the editor straight away.
  • Empty state. NEW With no chains, "No chains yet" and one line of explanation sit above the New chain row.
  • Rename. NEW A leading swipe "Rename" (primaryBlue) next to the long-press item, both opening the same alert with the current name. A blank or unchanged name is ignored.
  • Delete. Trailing swipe, and NEW in the long-press menu. It always asks first; the message names the saved results and the draft that go with the chain.
  • Accessibility. A row reads "<name>, <N> blocks" with Rename and Delete as custom actions, so neither depends on a swipe.
  • Tokens. Row, header and icon styling carry over from BlocksPageView. The empty state reuses the editor's (LTA-21): the ƒ icon in textTertiary, a headline and a footnote in textSecondary.
