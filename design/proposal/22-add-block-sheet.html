LTA-22 · Add-block sheet — proposal

Opened by "+" on a chain-outline row (LTA-21). Step 1 picks a block from a sectioned catalogue — blocks that don't fit the parent's output stay visible but disabled, with the reason. Step 2 sets the block's parameters and adds it. The same parameter step edits an existing block. Lo-fi: layout and states, not final visuals.

Notes for the implementer

  • Presentation. A sheet at the large detent over the chain outline, with its own navigation stack: catalogue → parameter step. Cancel dismisses without changes.
  • Parent line. "Under <parent>" plus a kind chip (Draws / Counts) so the reason behind disabled rows is visible at a glance.
  • Availability. Every block in the catalogue is always listed. Blocks whose input kind doesn't match the parent's output are disabled (not tappable) with a one-line reason under the name. Blocks that end a branch never open this sheet as a parent (see LTA-21).
  • Sections. Filter, Sort, Count — fixed order; blocks within a section in the order shown. New blocks (LTA-24, LTA-25, LTA-26, LTA-18, LTA-27) join their section.
  • x. Numeric keypad field plus a stepper; default 10; whole numbers ≥ 0; the stepper's "−" disables at 0. Invalid or empty input shows an inline error and disables Add/Save. The hint shows the parent's size when a previous run knows it.
  • Direction. Segmented Ascending / Descending with a one-line preview of what it means. Defaults: count descending, date and index ascending.
  • z (LTA-27). Same field + stepper, bounded 2 … x − 1 where x is the draw size of the source the chain runs against: the "+" disables at x − 1 and a larger typed value shows "Enter a whole number from 2 to <x − 1>." and disables Add/Save. When the draw size isn't known yet (never synced), only z ≥ 2 is checked here and a too-large z fails at run time ("z must be below this source's draw size"). Not drawn here.
  • Edit. Opens the parameter step alone, titled "Edit <block>", button "Save", with "Was <old value>" in the hint. Saving marks results stale (LTA-19).
  • Accessibility. Disabled rows read "<block>, unavailable, <reason>". The stepper exposes adjustable actions. At accessibility sizes the field and stepper stack vertically.
